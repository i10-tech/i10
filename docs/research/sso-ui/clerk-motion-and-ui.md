# Clerk's SSO admin UI: motion, layout, logos (the feel layer)

Source: clerk/javascript, shallow clone, `@formkit/auto-animate` 0.8.2 read from unpkg (`index.mjs`, not in the repo). Read-only; nothing run.
Shorthand: `UI` = `packages/ui/src`. `SSO` = `UI/components/ConfigureSSO`. `OP` = `UI/components/OrganizationProfile`. `AA` = auto-animate 0.8.2 `index.mjs`.
Wizard logic and copy are in `docs/research/clerk-sso/admin-ui.md`; not repeated.

## 0. The surprise: the wizard itself barely animates

The thing the owner remembers ("click something, something slides open out of nowhere") is NOT the wizard step change. Verified:

- Step change is an instant swap. `Wizard.Match` returns `null` or children (`SSO/elements/Wizard/Wizard.tsx:57-63`). No keyed transition, no exit. `direction` is computed (`reducer.ts:13`) but only read once, to pick the start sub-step (`SSO/steps/ConfigureStep/index.tsx:36,43`). Nested step change, Previous/Continue, and the "Step n/N" counter all swap instantly.
- Security page view switch (overview to wizard to connection page) is an instant swap: plain `if (view.kind === ...) return` (`OP/OrganizationSecurityPage.tsx:108-171`).
- Segmented IdP mode swap (URL vs manual) is a `switch` on `mode`, instant (`SSO/steps/ConfigureStep/saml/shared/IdentityProviderConfigurationForm.tsx:84-100`).
- Wizard error alerts (`<Alert>` under `card.error &&`) pop in with no animation: `SelectProviderStep.tsx:175-181`, `OrganizationDomainsStep.tsx:163-168`, `ActivateStep.tsx:101-106`, `ActiveConnectionAlert.tsx:17`. Test step error is a bare `<Text>` row (`TestConfigurationStep.tsx:134-155`).
- Activate success has no celebration: it calls `onExit()` and the view just swaps (`ActivateStep.tsx:40-44`).

So where does "slides open" come from? Three mechanisms, all small (section 1): (A) auto-animate on a parent where a closed row is swapped for an open card, (B) the Collapsible grid-rows reveal, (C) form feedback keyframes. Mechanism A is the one the owner feels, on the connection detail page (Name, Identity provider sections) and the domain card.

## 4. Provider logos

- Source: remote static CDN, `https://img.clerk.com/static/${id}.svg` (`packages/shared/src/constants.ts:30-31`, icon ids `okta`, `microsoft`, `google`, `saml`, `oidc` in `SSO/domain/providers.ts:24-61`). No bundled assets. Generic SAML and OIDC use the CDN ids `saml` and `oidc`, i.e. designed generic glyphs, not initials.

Sizes seen: 32px in picker cards (`$8`), 24px (`$6`) in the overview tile, 16px default. No `<img>`, so not selectable/draggable and no layout shift once cached.

Okta is in the list, so the Okta glyph flips with dark mode; Microsoft and Google keep full colour in both modes. Multicolour marks have no dark variant at all.
- Fallbacks: no `iconUrl` renders `ProviderInitialIcon` (letter tile) (`ProviderIcon.tsx:73-85`); custom connection uses `connection.logoPublicUrl` (`EnterpriseConnectionIcon.tsx:16`). `isLoading`/`isDisabled` dims to 0.5 opacity.

## Top 10 things that make it feel good (ranked, implementable)

1. Edit-in-place with auto-animate on a section wrapper. Pattern: `Closed` row and `Open` card are mutually exclusive children of one animated parent. Use `@formkit/auto-animate` defaults (250ms ease-in-out; add is 375ms `scale .98 + opacity 0->1`, held 50% then eased in; remove is 250ms ease-out pulled `position:absolute` so siblings reflow at once; siblings FLIP-translate). This single mechanism is the "slides open from nowhere" the owner means. Wrap `ul`s and card stacks the same way for row add/remove.
2. A 70-line `Collapsible` (grid `0fr -> 1fr`, `opacity`, 120ms ease-out, inner `overflow:hidden; min-height:0`, rAF before expanding, unmount on `transitionend` filtered to `target===currentTarget`, `inert` when closed). Use it for every conditional block (alert, extra fields, help). Add the 0.5rem bottom mask fade (registered `--cl-collapsible-mask-size`, 200ms) for polish.
3. Never change a button's width on loading: keep the label `visibility:hidden` and overlay a centered 12-16px spinner (400ms linear). Add `useSpinDelay` minDuration 425ms so quick calls do not flash a spinner. Keep Continue loading through the deferred step change (no idle flash).
4. Resume anywhere, derived from server state: land on the furthest reachable step, create the connection at provider pick, save per step. Stepper items are real buttons, disabled when unreachable.
5. Auto-verify instead of "Verify" buttons: poll the domain TXT every 10s only while visible, auto-attach on success, and cross-fade the TXT block into "Verified on <date>" with mechanism 1 (card children keyed by state). Poll test results every 2s until the first row, spinner + "waiting for your sign-in" in the empty table.
6. Pre-minted, one-click copy for every SP value: label above, readonly input, ghost 24px icon inside the right edge, icon swaps to a check for 1.5s. We should also add a visible "Copied" text and a live region (Clerk's gap).
7. One persistent footer bar (muted bg, top border, Reset far left, Previous outline, Continue solid) that is identical across wizard steps and nested sub-steps, with the "Step n/N" counter in the step header. The page never re-lays out, and a dense 13px type scale on a 4px grid keeps it calm.
8. Smart defaults that remove a decision: domain suggestion from the user's email (one click), default IdP mode = paste metadata URL, 4 provider cards + 1 generic OIDC card, OIDC variants collapsed to one card. We should add what Clerk lacks: deep link into the IdP admin page, numbered steps, and screenshots.
9. Contextual dialogs: Reset/Change/Remove open INSIDE the card (portal to the content ref, `position:absolute; inset:0; backdrop-filter: blur(0.5rem)`; 150ms fade + 180ms `translateY(0.5rem)->0` ease-out), require typing the org name to confirm. Do it better by adding an exit animation.
10. Inline form feedback that never jumps layout: fixed measured-height container (200ms height ease) with the message fading/translating in (`opacity 0->1`, `translateY(-5px)->0`, `max-height 0->6rem`, 450ms ease) and out (`translateY 0->5px`). Cheap version: Collapsible + key-faded text. Gate ALL of it on `prefers-reduced-motion` AND respond live (Clerk only reads it once), and add the missing wizard-step slide (e.g. 180ms `translateX(8px)->0` + opacity, direction from `direction`) that Clerk computes but never uses.
